# 架构文档索引

> `docs/architecture/*.md` 是**设计事实来源**（design source of truth）。两条前提：
> **① 每篇都标了状态；② 有冲突以代码为准**（`AGENTS.md` 红线）。

## 权威顺序

```
代码  >  docs/architecture/<具体篇>  >  docs/architecture/<总纲篇>  >  记忆 / 其它
```

- 架构文档**不是需求**，是**对现状与方向的最接近描述**。改了实现就回写文档（回写是任务的一部分，不是后续）。
- 标着「**草案**」的篇目 = 方向已定、部分未实现。凡标"预留 / 草案 / 待定"者**视为不存在**，不得据此按图索骥。
- `docs/review/` 是评审记录（外部工具的历史 findings），**不是设计文档**。
