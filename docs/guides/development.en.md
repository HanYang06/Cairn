# Development

## Environment

```powershell
uv sync                                  # install / sync dependencies (Python 3.14, uv.lock + Aliyun mirror)
```

The kernel has no vault knob: the vault root is always passed in by the caller
(`Kernel.create(root)` / `Kernel.open(root)`), and a development vault normally lives in
`<repo>/vault/` (git-ignored). The configuration root has one knob, `CAIRN_CONFIG`, used only to
redirect paths for tests and deployment — it is not a configuration item. The desktop shell adds
`CAIRN_VAULT` / `CAIRN_PYTHON` / `CAIRN_PYTHONPATH` (see [Quickstart](quickstart.md) §4).

## Common commands

```powershell
uv run pytest                              # all tests (with coverage; CI uses --cov-fail-under=80)
uv run pytest tests/core/test_conf.py -x   # one test
uv run ruff check .                        # lint (--fix fixes automatically)
uv run ruff format .                       # format (use --check before committing)
uv run mypy py_src tools scripts tests     # type check (strict)
uv run python scripts/spdx.py --check      # SPDX header gate (--fix inserts missing headers)
uv run python scripts/prose.py             # written-style gate (docs and comments must not be colloquial)
uv run python scripts/punct.py --report    # punctuation check (Chinese punctuation in comments / docstrings)
uv run deptry .                            # dependency audit (declared but unused / used but undeclared)
uv run lint-imports                        # architecture check (contracts in pyproject [tool.importlinter])
uv lock --check                            # is the lockfile in sync with the declarations
uv run pre-commit install                  # install the hooks first; the config alone does not run them
uv run pre-commit run --all-files          # the full gate before committing (13 hooks, see quality.md §4)
pnpm --dir app check                       # frontend gate (types / lint / styles / architecture / tokens / duplication / unit tests)
```

!!! tip "Order before committing"

    One command runs everything: `uv run pre-commit run --all-files`. For the Python side alone,
    `ruff → mypy → pytest`. The quality bar is defined in `.agents/skills/rules/references/quality.md`,
    and the **single source of truth** for configuration is `pyproject.toml`.

## Docs site

```powershell
uv run mkdocs serve            # local preview with hot reload → http://127.0.0.1:8000
uv run mkdocs build --strict   # the same build CI runs (broken links / missing pages / unknown config fail)
```

Build output lands in `site/` and is **not committed**. Read
[how to edit the docs](../contributing.md#editing-the-docs) before touching any page.

**Two languages**: the Chinese pages (`docs/**/*.md`) are the **basis of truth** — the author writes
them; the English pages (`docs/**/*.en.md`) are **machine-translated** from them. A page with no
English counterpart is served from the Chinese source, so the translation table is the honest state
of that — see [Translation status](../reference/i18n-status.md).

## Directory layout

```text
py_src/
  core/        L0 foundation: events / storage / configuration / exceptions (Qt-free, transport-agnostic)
  model/       domain landing spot (note, under reconstruction)
  app/         Python-side entry point: the kernel sidecar (python -m app.sidecar)
app/           Tauri shell + web frontend: app/src/ (React/TS), app/src-tauri/ (Rust shell)
tools/         importable development pieces (atomic writes and output helpers)
scripts/       gates / generators / packaging (no __init__.py; core and tools must not depend on it)
docs/          hand-written docs (the source of truth)
tests/         pytest cases
config/        configuration (value file and vocabulary, generated by running the program) + theme tokens
vault/         development vault (git-ignored)
```

Top-level packages always drop the `cairn.` prefix: `from core.storage import …`.
Layer boundaries and red lines are in [Conventions and red lines](conventions.md).

## Committing

- Commit messages follow **Conventional Commits** (`feat(ui): …` / `fix(core): …`), written in
  Chinese. **There is no commit-message hook** (removed on 2026-10-10); the format is a convention
  only.
- pre-commit runs 13 hooks (SPDX → written style → punctuation → magic budget → config declarations
  (`onconf check`) → ruff → deptry → architecture → mypy → lockfile → tests → frontend). A missing
  SPDX header is inserted automatically, after which `git add` again. **The hooks must be installed
  first** (see above).
