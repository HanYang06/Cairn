# 术语表

> 项目里的词有**明确所指**，混用会读错代码。这里只收"读了会误解"的词；
> 定义以代码与 `docs/architecture/*.md` 为准，本表只是索引。

## 存储（L0）

> 这一节是**现状**：与 [L0 存储设计](../architecture/storage-design.md) 和
> `py_src/core/storage/` 一一对应。

| 词 | 含义 | 不是什么 |
|---|---|---|
| **vault** | 库根目录：一个索引库 ＋ 若干 hub 目录（路径约定在 `core/storage/engine.py` 与 `core/init.py`） | 不是"保险箱"式的加密容器 |
| **hub** | `<root>/<hub>/packs/`：装若干载体；`packs/` 的存在即"这个目录算 hub"的判据 | 不是领域分区；代码里曾叫 bucket |
| **格 Slot** | 载体内的等长分配与定位单位；**一条记录至少占一格**，位置即 `(头格, 末格)` | 不是"格内偏移"（那是作废的旧模型） |
| **块 Block** | 存储单元的基座：拿到 ID 才有表、才能落盘与读回；字段落点由类体上的 `Attr` / `Body` 声明 | 不是"文件"；也不是"有 ID 就自动落盘的容器" |
| **`Attr`** | 类体上的**可索引**声明（`title: str = Attr("")`）：这个字段进块记录载荷，**并且进反表** | 不是"声明了却不索引"的半个开关；也不是类型判据 |
| **`Body`** | 类体上的**内容**声明（`lines: list[str] = Body([])`）：这个字段进内容记录、按内容地址去重 | 不是"块携带的正文指针"，也不是绑定语法 |
| **裸赋值** | `self.title = "…"`：照样落盘，**没有索引加持** | 不是"落不了盘" |
| **内容记录 / 块记录** | 前者载荷即内容、身份按内容签发；后者载荷是指针 ＋ 属性，身份是块自己的 | **各是独立的一条记录**（不是一个块一张表）；判据是载荷里的保留键 |
| **记录 record** | 载体里的一条自框定记录：总长 ＋ 校验和 ＋ 身份段长度 ＋ 身份段 ＋ 载荷；**顺扫即可切出，不依赖索引库** | 不是数据库的"行"（"行"指身份表里的那一行） |
| **保留键** | `\x00cairn.` 前缀的载荷键：`ref` / `attrs` / `body_fields` / `index` / `tombstone` | 不是业务键（前缀即"业务数据不可能占用"的命名空间） |
| **校验和** | 记录头里的 `crc32`，覆盖载荷，验"读到的是不是原文" | **不是内容寻址**（内容凭证走 ID 的摘要形态） |
| **ID** | 身份本身：`value_uuid`（`uuid4()`，比较有效）＋ `value_hash`（`sha256`，去重有效）＋ `name` ＋ `birth_time`（纳秒）＋ 位置段 | 不是裸字符串；也不是"指向身份的句柄" |
| **地址 address** | 即摘要形态凭证，回答"是哪份内容" | 不是物理坐标 |
| **载体 pack** | 追加写的载体文件，随机命名、定长格、写满封口线即换份 | 不是"包管理器"的包 |
| **封口 sealed** | **策略判断**："剩下的地方装不下下一格" | 不是落盘状态（文件里没有封印标记） |
| **墓碑 tombstone** | 追加在载体末尾的一条机制记录，载荷是某个**载荷摘要** | 不是"删掉了字节"（字节等 GC 回收） |
| **索引库 Index** | `<root>/catalog.db`：一个类型一张**身份表**、`hub` 登记、`meta`；**可重建的投影** | **不是真源**（真源是载体） |
| **身份表** | 一个用了 ID 的类型在库里占的那张表：表名 ＝ 类型名，列 ＝ `ID_FIELDS` 七列 | 不是"声明出来的表结构"（没有声明文件） |
| **索引块** | `AttrIndex` / `BodyIndex`：**直接继承 `Block`**，各有自己的身份表，只声明 `manages` 与 `holds` | 不是数据库的索引功能 |
| **正表 / 反表** | 正表是"某个块的某一列等于某个值"（存在索引块的载荷里）；反表是"值 → 哪些块"（**读的时候现算，不存**） | 反表**不落盘**——存下来就要增量维护，漏一处不报错、只是查不到 |
| **GC / `sweep`** | `core/storage/gc.py` 的 `sweep(engine)`：走同一条 slot / pack / hub 的路，换一套"谁还活着"的判据，把死字节收走并把索引库扶正 | 不是引擎的一个方法（模块级函数，返回 `SweepReport`）；也**没有触发点**——命令面与内核都不调用它 |

## 内核

> 这一节是**现状**（`py_src/core/`）。旧主轴的那套名字（`Core` / `Signal` / `ConfEngine` /
> `Managed` / 工具单元）随 2026-09-29 的重建整条删除（历史见 Git）。

| 词 | 含义 | 不是什么 |
|---|---|---|
| **Kernel** | 内核装配：库根 ＋ 存储引擎 ＋ 事件总线 ＋ 事件日志（`core/init.py`）；只做路径约定、`bind(engine)`、事件日志装配、失败钩子接日志四件事 | 没有 `store` / `load` / `patrol` / `repair` / `reindex` / `survey` / `compact` / `locate` |
| **bind / 那根线** | `Block` 的能力接到哪个库：**模块级、一个进程一根线**，`close()` 解开 | 不是"每个块自己记着往哪儿写" |
| **Bus / 事件总线** | 事件引擎：订阅、按注册顺序投递、异常隔离并交回失败清单（`core/event/bus.py`） | 不做决策，也没有解析器 |
| **Event** | 事件对象（冻结）：`type` / `source` / `subject` / `data` / `id` / `time`；字段名借 CloudEvents 口径 | 不代表实现该规范；也不进存储 |
| **事件目录** | 内核当前会发出的**两条**类型常量（`object.put` / `object.deleted`，`core/event/catalog.py`），发布与订阅都引它 | 不是三条（`budget.exhausted` 已删：配额那套机制不存在） |
| **事件日志** | `core/event/logs.py` 的 `EventLog`：**订阅的唯一一处**（一次订阅 `catalog.ALL`），按分流表 `ROUTES` 走诊断 / 落盘 / 反馈三路；落盘是 JSON Lines 的文本文件，得给落点才建 | **不是存储的记录**（不进载体、不建表、不占 ID）；也不是领域活动日志（那是业务语义，属领域层） |
| **存储引擎 Engine** | 块 ↔ 记录：分配 hub / pack / slot、编码、落盘、读回、摘块（`core/storage/engine.py`） | 不认识数据库 |
| **数据库引擎 Index** | 索引库那一侧：建身份表、写行、按身份查位置、登记 hub（`core/storage/db/engine.py`） | 不认识 slot / pack / hub |
| **异常层** | `core/exc.py` 的层级：`CairnError` 兜底，存储 / 配置 / 命令面各族细分；与日志的联动点在 `Bus` 的失败钩子 | 不声明没有抛出点的异常 |
| **配置 conf** | `core/conf/` 的声明引擎：声明即事实（声明期校验、类型判据），值落单份值文件 | 不是配置文件本身；取用点不抄默认值 |
| **命令面 Api** | `core/api.py` 的方法表，**七个方法**（`tables` / `hubs` / `rows` / `locate` / `record` / `stats` / `delete`）：读与诊断 | **没有 `store`**（写由领域块自己发起）；也不解领域载荷 |

## 领域（意图：`feature` 待重建；note 落点 `py_src/model/note/`）

> 以下多为**当前没有代码**的目标形态（`py_src/model/note/` 只有形状与载体）。

| 词 | 含义 | 不是什么 |
|---|---|---|
| **域 Domain** | **管理型对象**：单例、无 ID，管机制与策略（`Note` / `Project`） | 不是数据 |
| **载体（五个）** | `NoteData` / `NoteTag` / `NoteGroup` / `NoteAsset` / `NoteCanvas`：`Block` 子类，**有 ID、进库建表** | 不是"载荷内的结构" |
| **载荷内的结构** | `NoteLine` / `Span` / `Heading` / `Chunk` / `Figure` 等：普通值对象，**没有 ID、不登记不建表**，只活在各自载体的载荷里 | 不是载体 |
| **note body** | 正文 = **行序列**（`list`），一元素 = 一行 | 不是字符串 |
| **样式 Span** | 行内区间 `[start, end)` ＋ 一份 KV（CSS 属性名 → 值），只存非默认值 | 不是行属性 |
| **关系 Relation** | **由块自己表达**（块说它有哪些关系）；库只做索引，关系索引尚未设计、不预埋 | 不是字段；也不再是"一等 DB 行"（`edge` 表已于 2026-09-30 删除） |
| **领域载荷的规范化字节层** | 落点 `py_src/model/note/format/`，**未落地**：`cbor2` 编不出 dataclass，故 `NoteData.lines` 放 `NoteLine` 对象时存不下去 | 不是"已经能存行对象" |

## 界面（意图：Tauri 壳 + Web 前端）

> 以下多为**当前没有代码**的目标形态；工程落点是 `app/`（Tauri 壳 + Web 前端）。

| 词 | 含义 |
|---|---|
| **ui_tools** | Qt 时代的界面**工具箱**（声明树 / 编译 / 绑定 / 模型 / 主题）：层名已随 Qt 作废，职责由前端共享组件承担 |
| **App** | 应用**组合根 / 编排层**：组合内核 + 领域 + 界面；Python 侧入口在 `py_src/app/`（现仅边车），界面侧是 Tauri 壳 |
| **Facet** | 一个域的整套 UI 定义（分析器 + 组织器 + 包装器三合一），交给 App 编译挂载（Qt 实现已作废，去留待定） |
| **Slot** | App 根结构里的**命名槽位**（`expects=` 声明等谁的哪个部件；同上，待定） |
| **token / Theme** | 外观令牌**封闭词表**（唯一真源 `config/theme/tokens.json`）→ `gen:tokens` 生成 `tokens.css`，`check:tokens` 防漂移；组件只引用 `token.*`，禁硬编码 |
