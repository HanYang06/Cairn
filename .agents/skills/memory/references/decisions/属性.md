## 属性（现行；2026-10-02 值范式落地）

> 状态：**现行**。本文只记**现在成立的约束与理由**；过程与旧版本不在这里堆（那是 Git 的事）。
> 未定的写"未定"，**不假装已存在**。

### 一、属性是什么、落在哪

- 已定 · **属性 = 块上的小字段**，与内容分开：块自己声明，**跟着块记录走**。
  判据是两类内容的性质不同——内容是"按地址去重的大头"，属性是"跟块身份一起变的小字段"。
- 已定 · **属性不进内容记录**：塞进去等于把内容去重切碎（改一个标题就重写整份内容）。
- 已定 · **属性不落库列**：库只是索引；它的每一列都要能从载体算回来，而属性放进列就推不回来。
  落点是**块记录载荷的保留键** `\x00cairn.attrs`——与内容指针同一层，顺扫即可还原。
  载荷里没有这个键就是"这块没有属性"，不是坏记录。
- 已定 · **块身份随载荷**：同一份内容配上不同属性就是两个块，而内容面仍按地址去重，
  故只多一条块记录，内容不多存一份。
- 已定 · **写入期校验只有一条**：属性值编不进 CBOR 即报错（`AttrTypeError`）。
  按声明类型判空属未定（见 §三）。

### 二、怎么声明

- 已定 · **声明写在类体上，写成描述符**：`title: str = Attr("")`、`lines: list[str] = Body([])`。
  注解是字段类型（给 mypy 看），右值是落点声明。**声明即落点**：`Attr` 进块记录并进反表，
  `Body` 进内容记录，裸赋值照样落盘但没有索引加持。
- 已定 · **`Attr` 用了就进反表，没有开关**：不要索引就别声明——裸赋值本来就落盘。
  故不存在"声明了却不索引"这个中间态，`Attr` 也就**没有 `indexed=`**。
- 已定 · **它是描述符，不是类型判据**：实例里存的是**裸值**，
  `note.title = "标题"` 之后 `note.title` 交出的就是那个字符串。
  三条语义缺一条这套写法就不成立：类体上的声明描述落点而非共享的一份值；
  值存在实例自己的 `__dict__` 里；声明活得比任何一次赋值更久。
- 已定 · **声明必须放类体、不放 `__init__`**：放进构造里，这个实例字段的静态类型会变成声明类型，
  此后 `note.title = "标题"` 与它不符。类体是**字段类型与落点声明同时成立**的地方。
- 已定 · **类型只活在注解里（mypy 用），运行期不认注解**：故**不需要 mypy 插件**。
  注解按字段的真实类型写（`title: str = Attr("")` 而非 `Attr[str]`），
  故要点上 `# type: ignore[assignment]`——**这是这套写法已知的代价**：描述符的静态类型是
  `Attr[str]`，与注解声明的 `str` 不符。它换来的是声明与字段类型写在一行上、运行期零开销。
- 已定 · **默认值只有两个出处**：`Attr(字面值)` 与 `Body(容器字面值)`；
  类型不单独给（按注解算）。容器默认值在**实例第一次取值时现拷一份**（列表 / 字典 / 集合现拷，
  标量原样），故**实例之间不串**——类体上那个容器是共享的，直接交还就会串到所有实例。
- 已定 · **形状从类体上读，不从实例上记**：`kinds_of` 走 MRO、同名以子类为准、按声明处顺序。
  故**没显式赋过值的声明字段也在落盘之列**——只看 `vars()` 会把"带默认值就存"的字段整个漏掉，
  而且不报错（读回来像是"从没写过"）。

### 三、未定

- 未定 · **属性要不要在库里留一列**：留了才能按它查（否则只能全库顺扫块载荷）。
  它**不违反**"索引只做索引"——属性在块载荷里、顺扫可还原，故那一列是**物化缓存**。
  真正要裁的是另两条：容器类型没有中立列类型可落（只能存文本，"按它查"就无从谈起）；
  以及"全留"还是"只留确实要查的那几个"。**等真实查询需求**，不预埋。
- 未定 · **属性值要不要按声明类型校验**：判据现成（配置那一套类型词表），
  当前只在编码期拦下编不进去的值。

### 变更记录

> 一条一行的索引：**改了什么 → 为什么 → 否掉了什么 → 后果 → Git**。
> 详细过程不在这里（那是 `git show <hash>` 的事）；**与事实不符或已被更大变化取代的条目，删掉**。

- 2026-10-02 · **声明改回类体，形态定为描述符**：删掉"声明写在 `__init__` 里"（`attr(default=…)`、
  `factory=`、`type=`、`indexed=`、`__indexed__` 名单、零参探针、`TypeDecl`）整条口径；
  `Attr` / `Body` 改为描述符，默认值只留"字面值 ＋ 容器现拷"两个出处，
  并如实记下 `# type: ignore[assignment]` 这条已知限制。
  | 为什么：值范式落地（见 `storage/types.py` 与 `docs/architecture/storage-design.md` §3）——
  声明进构造会让实例字段的静态类型变成声明类型，此后赋值与它不符；描述符是唯一能让
  "类体上是声明、实例上是裸值"同时成立的做法。且 `attr(...)` 与 `conf` 同族那条口径已不成立
  （`conf` 是配置面的调用形，属性不需要第二个动词）。
  | 否掉了什么：把声明塞进 `__init__`；让 `Attr` 冒充成值（那 `note.title` 拿到的是声明对象）；
  为类型可见性养一个 mypy 插件；`indexed=` 开关与 `__indexed__` 名单。
  | 后果：属性类型不再有独立词表；"默认值三出处"缩成两处；
  值不是 CBOR 认得的写法仍在写路径当场报错（`AttrTypeError`）。
  | Git：见本次提交。
