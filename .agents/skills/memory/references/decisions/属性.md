## 属性（现行；2026-09-30 落第一版）

> 状态：**现行**。本文只记**现在成立的约束与理由**；过程与旧版本不在这里堆（那是 Git 的事）。
> 未定的写"未定"，**不假装已存在**。

### 一、属性是什么、落在哪

- 已定 · **属性 = 块上的小字段**，与 `body` 分开：块自己声明，**跟着块记录走**。
  判据是两类内容的性质不同——`body` 是"按地址去重的大头内容"，属性是"跟块身份一起变的小字段"。
- 已定 · **属性不进 `body`**：塞进去等于把内容去重切碎（改一个标题就重写整份内容）。
- 已定 · **属性不落库列**：库只是索引；它的每一列都要能从载体算回来，而属性放进列就推不回来。
  落点是**块记录载荷的保留键** `\x00cairn.attrs`——与 body 指针同一层，顺扫即可还原，
  故档一（可重建）照旧成立。载荷里没有这个键就是"这块没有属性"，不是坏记录。
- 已定 · **块身份随载荷**：同一份 `body` 配上不同属性就是两个块，而内容面仍按地址去重，
  故只多一条块记录，内容不多存一份。
- 已定 · **写入期校验只有一条**：属性值编不进 CBOR 即报错（`AttrTypeError`）。
  按类型判空属未定（见 §三）。

### 二、怎么声明

- 已定 · **声明写在子类的 `__init__` 里**（2026-10-01 改）：`self.title = attr(default="")`。
  声明与构造一处，子类 `super().__init__()` 之后接着声明就是扩展。
  **类体注解不算数**：函数体里的 `self.x: attr[str] = …` 会被 Python 丢掉
  （连求值都不发生，实测过），故性质只能由右边的标记给出。
- 已定 · **`attr` 与 `conf` 同族**：全小写入口、全局可用、不限定在哪一层。
- 已定 · **判据与配置共用一套**（`core.conf.types` 的 `spec_of` / `check_type`）：
  不为属性另立类型词表，于是不会出现"配置放行、属性拦下"这类两边各写一套才有的矛盾。
- 已定 · **缺省值三个出处**：`attr(default=…)`（字面值，类型按它推）、
  `attr(factory=list[str])`（工厂，类型按工厂推）、`attr(…, type=…)`（显式类型）。
  字面值每次拷一份、工厂每次现造一份，故**实例之间不串**。
- 已定 · **速查声明长在属性自己身上**：`attr(default="", indexed=True)`。
  类体的 `__indexed__` 名单**已删**——一条事实不写两遍（`attrindex` 现在读 `TypeDecl.indexed`，
  它由属性上的 `indexed` 汇总而来）。
- 已定 · **类型上返回缺省值的类型**：`attr(default="")` 在 mypy 眼里就是 `str`。
  故**不需要 mypy 插件**：`tools/mypy_plugin.py` 随类体注解一起删除。
- 已定 · **形状由一次零参探针现算**（见 [`内核.md`](内核.md) §七）：基座在子类构造跑完后
  扫一遍实例收货，故 `__init__` 必须能零参调用、声明不许依赖运行期条件。
- 已定 · **没声明过的赋值不算数**：`self.plain = "x"` 是普通实例状态，既不落盘、也不报错——
  内核不替它猜。
- 已定 · **登记只多一份、不落文件**：属性随类型登记进 `TypeDecl.attrs`，
  **不写进 `config/tables.yaml`**——声明文件描述的是**库的形状**，而属性不在库里。

### 三、未定

- 未定 · **属性要不要在库里留一列**：留了才能按它查（否则只能全库顺扫块载荷）。
  它**不违反**"索引只做索引"——属性在块载荷里、顺扫可还原，故那一列是**物化缓存**
  （`docs/architecture/storage-design.md` 的"两级台阶"），档位仍是 `derived`，
  **不需要**备份兜底。真正要裁的是另两条：容器类型（`list` / `dict`）没有中立列类型可落
  （只能存文本，`WHERE tags = …` 无意义）；以及"全留"还是"只留确实要查的那几个"。
  **等真实查询需求**，不预埋。
- 未定 · **属性值要不要按类型校验**：判据现成（`check_type`），当前只在编码期拦下编不进去的值。

  只做简单形式、不进声明文件。
  | 为什么：领域层加字段时既不进块也不进表，还**静默消失**——登记链只认 `ID`、ID 字段名与

  | 否掉了什么：把属性编进 `body`（切碎内容去重）；把属性只放索引列（让索引带真源）。
  | 后果：块记录载荷多一个保留键；`Storage.store` / `Kernel.store` 多一个 `attrs` 参数，
  `block_attrs(block)` 从实例取声明过的字段；未定的两项见 §三。

- 2026-10-01 · **声明从类体注解整条搬到 `__init__`**（`self.x = attr(default=…)`）：
  `attr` 由"只能当注解用的泛型类"改成**可调用的声明标记**（`default=` / `factory=` / `type=` /
  `indexed=` / `doc=`），速查声明随之上移到属性自身，`__indexed__` 名单与 `tools/mypy_plugin.py`

  | 为什么：作者裁定——`@dataclass` 与类体注解这一套在块上太绕，声明该和构造写在一处；
  "属性 / 载荷 / 配置"三者用各自的标记在同一个 `__init__` 里说清。
  | 否掉了什么：类体注解（`attr[T]`）这条路；为类型可见性养一个 mypy 插件；
  另立一个 `__indexed__` 名单。
  | 后果：`attr` 的调用面与 `conf` 对齐；块上不再用 `@dataclass`；属性类型判据仍是 `conf` 那一套。
